# Custom ambience

SonicTales generates every background sound procedurally, so it works out of the box.
To use real recordings instead, drop files here named after the tag:

    rain.wav  thunder.mp3  wind.ogg  night.flac  fire.wav  ocean.wav
    forest.wav  river.wav  city.wav  crowd.wav  birds.wav

Any format ffmpeg can read works. The file is looped with a 1-second crossfade and its level is
normalised, so just supply a clean recording of a few seconds to a minute.
Make sure you have the right to use and redistribute each sound (CC0 sources such as Freesound are a good start).
